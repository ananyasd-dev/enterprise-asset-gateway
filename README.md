# Enterprise IT Asset & Node Controller Gateway

An end-to-end full-stack IT infrastructure management and control system built using Python and Flask. This project simulates enterprise resource tracking, role-based network security partitioning, and live status node architecture monitoring.

## 🚀 Core Architectural Features
- **Role-Based Access Control (RBAC):** Distinct administrative and standard terminal dashboard panels to securely isolate system management.
- **Compliance & License Auditing:** Dynamic status checks tracking software deployment validity and vendor distribution contracts.
- **Node Monitoring Telemetry:** Live heartbeat check tracking system host states (`Online` / `Offline`) mapping infrastructure operational workflows.

## 🛠️ Technology Stack
- **Backend Architecture:** Python 3, Flask Web Framework, SQLite (Relational Database)
- **Frontend Core:** HTML5, CSS3 UI Components, JavaScript (Asynchronous state configuration updates)
- **Data Architecture:** Embedded relational database service initializing telemetry schemas automatically.
